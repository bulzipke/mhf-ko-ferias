
# Monster Hunter Frontier ferias 한국어판
일본의 몬스터 헌터 프론티어(MHF) 데이터베이스·시뮬레이터 사이트 **ferias**를 한국어로 옮긴 비공식 미러입니다.

👉 **사이트 바로가기: https://ferias.bulzipke.com**

## 📌 소개
ferias는 MHF의 무기·방어구·소재·스킬·퀘스트 데이터와 스킬 시뮬레이터, 데미지 계산기를 제공하는 사이트입니다. 이 저장소는 그 페이지와 스크립트를 한국어로 번역한 것이며, 용어는 한국어 패치 [mhf-ko-localization](https://github.com/bulzipke/mhf-ko-localization)의 게임 내 표기에 맞추는 것을 원칙으로 합니다.

## ⚠️ 저작권 안내 (Disclaimer)
* `원작`: 원본 사이트 [ferias](http://ferias.life.coocan.jp/)의 데이터 정리, 페이지 구성, 스크립트에 대한 권리는 **ferias 원작자**에게 있습니다. 이 저장소는 원작자와 관계없는 **비공식 번역 미러**입니다.
* `게임 데이터`: 몬스터 헌터 프론티어의 모든 텍스트·이미지·게임 데이터에 대한 저작권은 `Capcom Co., Ltd.`에 있습니다.
* `라이선스`: 원저작물이 포함되어 있으므로 이 저장소는 별도의 오픈소스 라이선스를 지정하지 않습니다. 번역·수정 기여는 이 미러를 개선하는 데 쓰입니다.
* `면책 조항`: 수치와 정보는 '있는 그대로(as is)' 제공되며, 실제 게임과 다를 수 있습니다.

## 🔤 용어 기준
**게임 안에서 보이는 표기가 기준입니다.** 번역이 애매할 때는 [mhf-ko-localization](https://github.com/bulzipke/mhf-ko-localization)의 `번역중` 폴더에서 **일본어 원문(Original 열)으로 검색**해 한국어(Translation 열)를 확인해 주세요.

| 찾는 것 | 파일 |
|---|---|
| 아이템·소재·무기·방어구 이름과 설명 | `번역중/mhfdat.csv` |
| 스킬 이름, 메뉴·UI 문구, 시스템 메시지 | `번역중/mhfpac.csv` |
| 퀘스트·이벤트 관련 문구 | `번역중/mhfinf.csv` |

자주 헷갈리는 표기 몇 가지:
* 속성은 한자음으로 씁니다 — 화·수·뇌·빙·용, 광(光)·암(闇)·풍(風)·향(響)·주(奏)·뇌극·천상·치동·흑염·홍마·작영·황명
* 장비 부위는 머리·몸통·팔·허리·다리 (스킬 시뮬레이터 장비 목록만 '양팔')
* 수렵피리 설명의 '선율'(旋律)은 속성 '주'(奏)와 다른 말입니다

## 🛠 제보 및 기여
번역 오류, 어색한 문장, 화면이 깨지는 곳을 발견하시면 언제든 알려 주세요!
1. 제보:
    * [Issues](../../issues)에서 양식을 골라 작성해 주세요. **페이지 주소와 스크린샷**이 있으면 가장 빠르게 고칠 수 있습니다.
    * 게임 안의 번역 문제는 [mhf-ko-localization Issues](https://github.com/bulzipke/mhf-ko-localization/issues)로 보내 주세요.
2. 직접 수정:
    * 이 저장소를 `Fork`한 뒤 수정 사항을 커밋하고 `Pull Request`를 보내 주세요.
    * 수정 전에 [CONTRIBUTING.md](CONTRIBUTING.md)를 꼭 읽어 주세요. 자동 생성 파일과 스크립트 주의 사항이 있습니다.
